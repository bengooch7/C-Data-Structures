# C Libraries
An old learning repository for C data structures

## What is this?
This repository was created as a backup of code I had written when learning the C programming language. It contains common data structures used in software engineering.

- Linked list
- Queue
- Simple Server
- Threadpool

Each data structure was written to satisfy a test suite provided to me by a co-worker and there are likely edge cases and errors that were not caught at the time.

*Disclaimer*: This repository should only be used as a reference.
